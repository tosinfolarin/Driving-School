TRINITY DRIVING SCHOOL

Welcome to Trinity driving school, a driving school which offers theory support and practical support but also the opportunity to search for driving schools in the specified location of your choice. This is a website that will take you from little to no experience of driving to booking your practical exam. The website contains a page with testimonials from previous customers, information about the driving instructor and frequently asked questions related to driving. An exciting feature of the website is the Test Questions page which allows us users to practice their theory in preparation of their theory exam. The resources on this page stemmed from different places.

This multiple choice Theory test practice quiz was inspired by a youtube tutorial:
https://www.youtube.com/watch?v=VMZ7lcSdVnY

The questions used for the Theory Quiz mainly came from:
https://theorytest.org.uk/#start-practice
https://mocktheorytest.com/highway-code/car/all/50/


The 'show me' 'tell me' questions list came from:
https://www.gov.uk/government/publications/car-show-me-tell-me-vehicle-safety-questions/car-show-me-tell-me-vehicle-safety-questions

The web application also offers users the ability to see other available driving schools in the area of their choice. Origianlly this was created using a Yelp API and was implemented with the help of this youtube tutorial:
https://www.youtube.com/watch?v=gSgiKeNUGfU&list=PL1Nml43UBm6fmZZDeu-FDt5pozS2rSuff&index=16
The GitHub Link for the code in the youtube tutorial is:
https://github.com/productioncoder/yelp-frontend
